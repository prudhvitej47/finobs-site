Finance Observability

Finance Observability is a personal, single-user application that runs only on its owner's own computer. It reads the owner's financial statements (bank, loan, investment, insurance and payslip documents), builds a local ledger with a full audit trail, and shows descriptive reports about the owner's own financial position.

The application is not offered to the public, has no accounts or sign-ups, and does not operate any server that receives user data.

Google account access

The owner connects their own Gmail account so the application can find statement emails from senders the owner has configured and save the PDF attachments to the owner's computer. It can also send the owner a short notification email when an expected statement is missing.
