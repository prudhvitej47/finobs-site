Privacy Policy

Finance Observability · Effective 22 October 2026

Who uses this application

Finance Observability is a personal application used by one household: its owner and the owner's spouse. It is not offered to the public. There are no sign-ups, no user accounts, and no other users.

What Google user data is accessed

  • Gmail read-only access (https://www.googleapis.com/auth/gmail.readonly). Each household member who connects their Gmail account grants this access separately. The application searches only for messages that match senders, subjects and attachment types that the owner has configured (bank, card, investment, insurance and payslip statements), and downloads the matching PDF attachments. It does not read, index or analyse any other email, and it never sends, changes or deletes email.

How the data is processed and stored

  • Downloaded attachments are processed only on the owner's own computer. The attachments and all data derived from them are stored on that computer, in an encrypted database. Attachments are kept password-protected, as received, in the owner's own cloud storage folder.
  • OAuth tokens and statement passwords are stored in the operating system's secure keychain.
  • A summary of the household's finances is encrypted on the owner's computer and sent only to the household's own phones, over a private network that is not reachable from the internet. Only those phones hold the key to decrypt it.
  • Encrypted backups of the database are stored in cloud storage that the owner controls. The storage provider cannot read them.
  • No Google user data is sent to the developer, to an analytics service, or to any other third party.

Sharing

Google user data is not sold, shared, transferred, or used for advertising, and is not used to train any machine-learning or AI model. The household's data is visible only to the two household members.

Limited Use

Finance Observability's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Each household member can revoke access at any time at myaccount.google.com/permissions. Deleting the application's local data folder, the app on each phone, and the encrypted backups removes all stored data.
