Privacy Policy

Finance Observability · Effective 27 September 2026

Who uses this application

Finance Observability is a personal application used only by its owner. It runs on the owner's own computer. There is no hosted service, no user accounts, and no other users.

What Google user data is accessed

  • Gmail read-only access (https://www.googleapis.com/auth/gmail.readonly). The application searches only for messages that match senders, subjects and attachment types that the owner has configured, and downloads the matching PDF attachments. It does not read, index or analyse any other email.
  • Gmail send access (https://www.googleapis.com/auth/gmail.send). Used only to send short notification emails from the owner's account to the owner (for example, "an expected statement is missing"). These emails contain no financial figures or account numbers.

How the data is stored

Downloaded attachments and all data derived from them are stored only on the owner's own computer (and in the owner's own cloud storage folder). OAuth tokens are stored in the operating system's secure keychain. No Google user data is sent to the developer or to any third-party server.

Sharing

Google user data is not sold, shared, transferred, or used for advertising, and is not used to train any machine-learning or AI model.

Limited Use

Finance Observability's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the application's local data folder removes all stored data.
